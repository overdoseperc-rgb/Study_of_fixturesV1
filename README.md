# КТ № 2 — Вариант 1. Изучение фикстур

Проект создан по разделу «Вариант 1» приложенного задания.
`strings.py`: длина строки и сохранение UTF-8 без добавления перевода строки.
`main.py`: пример работы, создаёт `string.txt` в текущей папке.
`tests/conftest.py`: параметризованная строковая фикстура и SQLite-фикстура scope=function.
Для каждого теста создаётся отдельная БД; после yield в finally удаляются записи,
проверяется очистка, закрывается соединение и удаляется файл БД, даже при падении теста.
Тесты сохраняют файлы только во временные каталоги pytest.

## Запуск
Требуется Python 3.10 или новее. Распакуйте архив и откройте терминал в папке проекта.
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
.venv\Scripts\python -m pytest -v
```
В Linux/macOS используйте `python3` при создании окружения и `.venv/bin/python` вместо `.venv\Scripts\python`.
SQLite, CSV и JSON входят в стандартную библиотеку; дополнительная зависимость — только pytest.

## Проектирование тестового набора
Техника: классы эквивалентности, граничные случаи и полное комбинирование факторов.
Для сохранения используется декартово произведение пяти видов строк и двух состояний файла
(новый/существующий): 10 комбинаций. Сравнение байтов обнаруживает ошибки кодировки,
лишние переводы строк, дописывание вместо перезаписи и изменение CRLF.
Длина: пустая строка, многострочная, пробелы, кириллица и CRLF; эталоны заданы числами.
Четыре неверных типа проверяются на TypeError. SQLite: четыре независимых теста
вставки/чтения, включая кавычку; каждый проверяет изначально пустую таблицу.

Выбор подмножества (как в теоретической части задания):
```powershell
.venv\Scripts\python -m pytest tests/test_strings.py -v
.venv\Scripts\python -m pytest tests/test_strings.py::test_length -v
.venv\Scripts\python -m pytest -k database -v
```
